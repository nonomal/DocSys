# API Reference

## Browser Use AI
- **Endpoint**: External API (browser-use.com)
- **Auth**: API key required
- **Response**: JSON with AI-generated results from autonomous browsing

## Error Codes
| Error | Message |
|-------|---------|
| 400 | Empty task description |
| 401 | API key not configured |
| 503 | Browser-use API unavailable |
| 504 | Task timeout |
