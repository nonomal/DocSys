# API Reference

## Move Document
- **Endpoint**: `POST /Doc/move.do`
- **Auth**: Required
- **Response**: JSON confirmation

## Error Codes
| Code | Message |
|------|---------|
| 400 | Invalid request |
| 401 | Unauthorized |
| 403 | Permission denied |
| 404 | Document or target folder not found |
| 500 | Server error |
